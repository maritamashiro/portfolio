# Cabinet study — full collection

Review route: `/cabinet-study/`. The original homepage remains available for comparison.

All eight projects follow the canonical order in `content/portfolio-project-questions.md`. Roughly square, lightly hand-drawn compartments of subtly different widths and heights contain smaller objects with generous space. Desktop uses three uneven columns beside the introduction, with different divisions and shelf heights in each row. Narrower layouts put the introduction above the cabinet, then use two uneven columns on mobile.

Each compartment has its number and project name together at the top left. The slightly smaller project question (12px on desktop, 11px on mobile) appears at the bottom on hover or keyboard focus, and stays visible on touch devices. Objects remain links to their project pages.
