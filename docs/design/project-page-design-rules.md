# Portfolio project-page design rules

Based on the approved Xenoflora Olfacta first version.

## Visual character

A spacious, personal cabinet of curiosities. Combine documentary photographs, photographic cutouts, original sketches, and occasional handwritten graphic assets. Use a flat ivory background and let the projects supply most of the color. Keep enough empty space for each composition to read clearly.

## Palette

| Role | Color |
| --- | --- |
| Background | Ivory `#FAF6EE` |
| Main text | Near-black `#211E1C` |
| Accent | Magenta `#EB007A` |

Use magenta for annotations, arrows, active navigation marks, and the closing question. Preserve the original colors of project photographs and materials.

## Typography

| Element | Typeface and treatment |
| --- | --- |
| Project title | Pastel Crayon, uppercase, largest text on page |
| What-if subtitle | Courier Prime Regular, large, sentence case |
| Authors | Courier Prime Regular, noticeably smaller than the description |
| Description and body | Courier Prime Regular |
| Main sections | Courier Prime Regular, large, sentence case |
| Subsections | Courier Prime Regular, smaller than main sections and larger than body |
| Captions and annotations | Courier Prime Regular |
| Closing question | Courier Prime Bold, large, magenta |

Pastel Crayon is reserved for the project title within the project page. Maintain hierarchy through scale and spacing. Keep body copy in sentence case.

Courier Prime's lightest official weight is Regular. The selected treatment uses Regular with slightly increased letter spacing for an airy impression. The current mockup uses approximately `0.035em` tracking for regular text. Treat this as a starting point for browser implementation and check readability at the final size.

The current type proportions are approximately 4.5 times body size for the project title, twice body size for main headings and the closing question, 1.8 times for the subtitle, 1.45 times for subsections, and 0.8 times for authors. These describe the mockup's proportions rather than fixed responsive specifications.

Pastel Crayon's available sample is personal-use-only with a limited character set. Resolve the appropriate license before publishing the font on the portfolio.

## Page sequence

### 1. Opening

- Project title.
- A subtitle beginning with “What if…”, placed immediately below the title with a small gap.
- A larger gap, then a small author credit beginning “A project by…”. Include the relevant collaborators.
- A brief description explaining the project in accessible language.
- The image collage, positioned close enough to the description to feel connected.

Keep the title and subtitle together as a visual group. Give the author credit its own quiet position between the subtitle and description.

### 2. Project experience collage

Show the encounter before the detailed technical explanation. Prioritize people interacting, the artifact in context, and details that convey its material or sensory character.

- Vary image sizes and positions.
- Combine rectangular photographs with selected transparent cutouts and original drawings.
- Allow controlled overlap, keeping essential details and faces readable.
- Preserve generous empty space around the composition.
- Use short magenta annotations where they help explain a gesture, behavior, or detail.
- Position each annotation close to the tail of its arrow. Point the arrowhead at the relevant detail.
- Use Mariana's supplied textured arrow assets, adapted to the magenta accent, with suitable rotation and scale.

Retain the identity and documentary accuracy of the project. Use actual project materials and identify illustrative placeholders during design reviews. Select cutouts where the silhouette helps the composition.

### 3. Design and fabrication

Use the consistent main section title **Design and fabrication** across projects.

Begin with a short overview of how the project was developed. Add project-specific subsections as needed, such as **Materials and form**, **Scent and interaction**, **Electronics**, or **Workshop design**. Select only headings supported by the project.

Use original sketches, process photographs, material tests, and technical details alongside the text. Explain the decisions and mechanisms needed to understand the work.

### 4. Out in the world

Use the consistent main section title **Out in the world**, at exactly the same typographic level as **Design and fabrication**.

Include relevant exhibitions, publications, deployments, or other documented outcomes. Use exhibition photographs or publication thumbnails when available.

For an exhibition entry, place the image on the left. Place its caption immediately to the right, aligned with the top edge of the image. The caption itself is left-aligned. Keep the gap small enough that the image and caption clearly belong together.

Only include outcomes appropriate to the project's current status. The approved Xenoflora version shows FAB2026 in Boston and omits the pending TEI submission. If a project has no relevant outcomes, omit this section.

### 5. Closing question

End with a project-specific, open-ended question that invites the visitor to imagine, reflect, or contribute an interpretation.

Set it in large Courier Prime Bold and magenta `#EB007A`. Give it space after the preceding section and wrap it naturally if needed.

Xenoflora's question is “What do you think an alien flower smells like?”

## Shared navigation

Keep the five-section navigation consistent across project pages.

**Work · On my desk · Illustration · About me · Contact**

The project page belongs within Work. Use a small magenta mark to indicate the active section.

## Applying the rules

Keep the opening sequence, type roles, palette, main section names, and closing-question treatment consistent. Compose each project's collage around its own material and interaction. Adapt subsection names and image selection to the project.

Responsive layouts and exact browser typography remain to be tested. On narrow screens, preserve reading order, reflow the collage, and place exhibition captions directly below their images when side-by-side placement becomes cramped.
